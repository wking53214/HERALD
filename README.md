# HERALD

## **The Governed Natural-Language Interpretation Boundary**

### **A Domain-Agnostic Linguistic Control Layer for Systems That Must Make Governed Decisions**

> **HERALD does not decide what language means in a governed domain. It determines what can safely be carried forward from language into a governance system — and preserves the uncertainty, provenance, source relationship, and refusals along the way.**

---

# **What HERALD Is**

HERALD is a **natural-language interpretation boundary**.

Its purpose is to sit between:

UNSTRUCTURED LANGUAGE
        │
        ▼
      HERALD

        ▼

        ▼

        ▼
DOMAIN GOVERNANCE
